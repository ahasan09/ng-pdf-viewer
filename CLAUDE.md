# PDF Viewer

Minimal Angular 10 application scaffolded for PDF viewing (PDF library not yet integrated).

## Tech Stack
- Angular 10
- TypeScript

## Project Structure
```
pdf-viewer/
├── src/
│   └── app/
├── angular.json
└── package.json
```

## Development
```bash
# Install dependencies
npm install

# Run development server
ng serve

# Build
ng build --prod
```
